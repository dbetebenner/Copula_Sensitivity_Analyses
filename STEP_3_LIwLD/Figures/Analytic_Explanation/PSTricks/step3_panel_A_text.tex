    \textbf{\textcolor{black}{A.\enspace Independent cross-sectional inputs}}

    \vspace{6pt}
    The starting point is two independent cross-sectional samples:
    prior-grade reference percentiles $U = F_X^{\mathrm{ref}}(x_i)$ and
    current-grade reference percentiles $V = F_Y^{\mathrm{ref}}(y_j)$.

    \vspace{4pt}
    Crucially, there is \emph{no student-level linkage} between these
    samples---we cannot match any $u_i$ to its corresponding~$v_j$.
    This is exactly the situation faced by international assessments such
    as TIMSS, where Grade~4 and Grade~8 cohorts are sampled independently.

    \vspace{4pt}
    The distributions of~$U$ and~$V$ are the only observables; all
    subsequent inference proceeds from these marginals alone.
