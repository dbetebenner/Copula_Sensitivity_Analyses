# STEP 3 PSTricks Infographic (V2)

## Figure Theme

**Longitudinal Inference Without Longitudinal Data**

This title/theme is the canonical framing for the current infographic and should be preserved in downstream AI context artifacts.

Publication-grade 2x4 PSTricks/LaTeX infographic explaining how STEP 3 infers a latent growth regime $\widehat{H}_S$ from unlinked cross-sectional data.

Framing used in STEP 3: **controlled canonical choices with quantified error**:
- Canonical baseline copula (from STEP 1),
- Canonical stochastically fitted growth regime (Beta family in STEP 3 production runs).

## Active panel layout

The current V2 assembly uses:
- **Top graphic row:** `A`, `B1`, `B2`, `C`
- **Bottom explanatory row:** `A`, `B1B2` (shared), `C`

| Conceptual column | Top row (graphic) | Bottom row (text artifact) |
|-------------------|-------------------|----------------------------|
| **A** | Independent U & V marginal densities (no student-level pairs) | `step3_panel_A_text.tex` |
| **B1** | Reverse-engineer regime landscape over $(m,\kappa)$ | `step3_panel_B1B2_text.tex` (shared B1/B2 narrative) |
| **B2** | Forward CDF check in v-space | `step3_panel_B1B2_text.tex` (shared B1/B2 narrative) |
| **C** | Inferred growth regime density $f_S(p)$ | `step3_panel_C_text.tex` |

## Workflow

1. **Panel A:** Observe unlinked marginals $F_U(u)$ and $F_V(v)$ (no student-level pairs).
2. **Panel B1:** Estimate subgroup regime by minimum distance over canonical Beta family:
   $\widehat{H}_S=\arg\min_{H\in\mathcal{H}_{\mathrm{Beta}}}\,W_1(F^{\mathrm{obs}}_{V,S},F_H)$.
3. **Panel B2:** Forward map with baseline kernel and candidate regime:
   $F_H(v)=\mathbb{E}_{U}\!\left[H\!\left(F_0(v\mid U)\right)\right]$.
4. **Panel C:** Display recovered density $f_S(p)=H_S'(p)$ and summary mean SGPc.

Key identifying assumption in this infographic: $P\perp U$ within subgroup.

## Notation

Canonical macros defined in `step3_styles.tex`:

| Macro | Renders |
|-------|---------|
| `\HS` | $H_S$ |
| `\HShat` | $\widehat{H}_S$ |
| `\FH` | $F_H$ |
| `\FHhat` | $\widehat{F}_H$ |
| `\Fobs` | $F_{\mathrm{obs}}$ |
| `\Fzero` | $F_0$ |
| `\SGPcFlow` | SGPcFlow |
| `\Wone` | $W_1$ |

### Mathematical notation

- $U,V$: prior/current reference quantiles (pseudo-observations)
- $P,P_S$: latent conditional percentile (SGPc on $[0,1]$)
- $H_S(p)=\Pr(P_S\le p)$: subgroup growth-regime CDF
- $F_0(v\mid u)=\frac{\partial}{\partial u}C_0(u,v)$: baseline conditional CDF kernel
- $Q_0(p\mid u)=F_0^{-1}(p\mid u)$: baseline conditional quantile kernel
- $F_H(v)=\mathbb{E}_{U}[H(F_0(v\mid U))]$: predicted current marginal under regime $H$
- $\mathcal{H}_{\mathrm{Beta}}=\{H_{m,\kappa}:P\sim\mathrm{Beta}(\kappa m,\kappa(1-m))\}$: candidate family
- $\widehat{H}_S=\arg\min_{H\in\mathcal{H}_{\mathrm{Beta}}}W_1(F^{\mathrm{obs}}_{V,S},F_H)$

Uniform baseline in this parameterization is $H(p)=p$ at $(m,\kappa)=(0.5,2)$, i.e. $\mathrm{Beta}(1,1)$.

apply_custom_bounding_box <- function(ps_file, bbox) {
  if (is.null(bbox)) return(TRUE)
  if (length(bbox) != 4 || any(!is.finite(bbox))) return(FALSE)

  bbox <- as.integer(round(bbox))
  if (bbox[1] >= bbox[3] || bbox[2] >= bbox[4]) return(FALSE)

  ps_lines <- readLines(ps_file, warn = FALSE, encoding = "UTF-8")
  bb_idx <- grep("^%%BoundingBox:", ps_lines)
  hr_idx <- grep("^%%HiResBoundingBox:", ps_lines)

  if (length(bb_idx) == 0 && length(hr_idx) == 0) return(FALSE)

  if (length(bb_idx) > 0) {
    ps_lines[bb_idx] <- sprintf(
      "%%%%BoundingBox: %d %d %d %d",
      bbox[1], bbox[2], bbox[3], bbox[4]
    )
  }

  if (length(hr_idx) > 0) {
    ps_lines[hr_idx] <- sprintf(
      "%%%%HiResBoundingBox: %.6f %.6f %.6f %.6f",
      bbox[1], bbox[2], bbox[3], bbox[4]
    )
  }

  writeLines(ps_lines, ps_file, useBytes = TRUE)
  TRUE
}

compile_pstricks <- function(name) {
  cat(sprintf("  [PSTricks] %s ...", name))

  old_wd <- setwd(pstricks_dir)
  on.exit(setwd(old_wd), add = TRUE)

  rc <- system2("latex", c("-interaction=nonstopmode", name),
                stdout = FALSE, stderr = FALSE)
  if (rc != 0) { cat(" FAIL (latex)\n"); return(FALSE) }

  system2("dvips", c("-E", name, "-o"), stdout = FALSE, stderr = FALSE)

  ps_file  <- paste0(name, ".ps")
  pdf_file <- paste0(name, ".pdf")

  if (!file.exists(ps_file)) { cat(" FAIL (dvips)\n"); return(FALSE) }

  bbox <- custom_bounding_boxes[[name]]
  if (!is.null(bbox)) {
    ok_bbox <- apply_custom_bounding_box(ps_file, bbox)
    if (!ok_bbox) {
      cat(" FAIL (BoundingBox)\n")
      return(FALSE)
    }
    cat(sprintf(" bbox[%d %d %d %d]", bbox[1], bbox[2], bbox[3], bbox[4]))
  }

  system2("gs", c("-q", "-dALLOWPSTRANSPARENCY", "-dBATCH", "-dNOPAUSE",
                  "-dEPSCrop", "-sDEVICE=pdfwrite", "-dCompatibilityLevel=1.4",
                  paste0("-sOutputFile=", pdf_file), ps_file),
          stdout = FALSE, stderr = FALSE)

  if (!file.exists(pdf_file)) { cat(" FAIL (gs)\n"); return(FALSE) }

  file.copy(pdf_file, file.path(output_dir, pdf_file), overwrite = TRUE)
  cat(sprintf(" OK (%s bytes)\n", format(file.size(pdf_file), big.mark = ",")))
  TRUE
}

for (i in seq_len(nr)) {
  for (j in seq_len(nc)) {
    val <- z_log[i, j]

    g <- round(strtoi(substr(hex, 4, 5), 16L) / 255, 3)

    x0 <- mean_vals[j] * 100 - dx * 50

      sprintf("\\definecolor{%s}{rgb}{%s,%s,%s}%%", tag, r, g, b),
      sprintf("\\psframe*[linecolor=%s](%.4f,%.4f)(%.4f,%.4f)%%",
              tag, x0, y0, x1, y1))

format_cross_table <- function(cross_df) {
  if (is.null(cross_df) || nrow(cross_df) == 0) {
    return(c(
      "| Content area | 1-year | 2-year | 3-year | 4-year |",
      "|---|---|---|---|---|",
      "| unavailable | - | - | - | - |"
    ))
  }

  spans <- sort(unique(cross_df$year_span))
  preferred_area_order <- c("MATHEMATICS", "READING", "WRITING", "ELA")
  areas <- unique(cross_df$content_area)
  areas <- c(intersect(preferred_area_order, areas), setdiff(sort(areas), preferred_area_order))

  header <- c("| Content area |", paste(sprintf("%d-year", spans), collapse = " | "), "|")
  sep <- c("|---|", paste(rep("---", length(spans)), collapse = "|"), "|")
  lines <- c(paste0(header, collapse = ""), paste0(sep, collapse = ""))

  for (area in areas) {
    cells <- c()
    for (span in spans) {
      row <- cross_df[cross_df$content_area == area & cross_df$year_span == span, , drop = FALSE]
      if (nrow(row) == 0) {
        cells <- c(cells, "-")
      } else {
        cells <- c(cells, sprintf("(%.2f, %.2f)", row$rho[1], row$df[1]))
      }
    }
    lines <- c(lines, sprintf("| %s | %s |", area, paste(cells, collapse = " | ")))
  }

  lines
}

build_plain_fallback <- function(rel_files, max_len) {
  out <- c(
    "# AI_CONTEXT_REPOMIX (Fallback Plain Pack)",
    "",
    "Generated by `step3_build_ai_context.R` because `repomix` was unavailable or failed.",
    "",
    sprintf("Root: %s", pstricks_dir),
    ""
  )

  bytes_used <- sum(nchar(out, type = "bytes")) + length(out)
  truncated <- FALSE

  for (rel in rel_files) {
    abs <- file.path(pstricks_dir, rel)
    if (!file.exists(abs)) next
    lines <- readLines(abs, warn = FALSE, encoding = "UTF-8")
    block <- c(
      sprintf("===== BEGIN FILE: %s =====", rel),
      lines,
      sprintf("===== END FILE: %s =====", rel),
      ""
    )
    block_bytes <- sum(nchar(block, type = "bytes")) + length(block)
    if ((bytes_used + block_bytes) > max_len) {
      truncated <- TRUE
      break
    }
    out <- c(out, block)
    bytes_used <- bytes_used + block_bytes
  }

  if (truncated) {
    out <- c(
      out,
      sprintf(
        "[TRUNCATED] Bundle reached --max-chars limit (%s bytes).",
        format(max_len, big.mark = ",")
      )
    )
  }

  out
}

xml_cdata_safe <- function(x) {
  gsub("]]>", "]]]]><![CDATA[>", x, fixed = TRUE)
}

build_xml_fallback <- function(rel_files, max_len) {
  body <- c(
    "<?xml version=\"1.0\" encoding=\"UTF-8\"?>",
    "<repomix_fallback>",
    sprintf("  <root>%s</root>", pstricks_dir),
    "  <files>"
  )

  bytes_used <- sum(nchar(body, type = "bytes")) + length(body)
  truncated <- FALSE

  for (rel in rel_files) {
    abs <- file.path(pstricks_dir, rel)
    if (!file.exists(abs)) next

    txt <- paste(readLines(abs, warn = FALSE, encoding = "UTF-8"), collapse = "\n")
    txt <- xml_cdata_safe(txt)

    block <- c(
      sprintf("    <file path=\"%s\"><![CDATA[", rel),
      txt,
      "]]></file>"
    )

    block_bytes <- sum(nchar(block, type = "bytes")) + length(block)
    if ((bytes_used + block_bytes) > max_len) {
      truncated <- TRUE
      break
    }

    body <- c(body, block)
    bytes_used <- bytes_used + block_bytes
  }

  body <- c(body, "  </files>")
  if (truncated) {
    body <- c(
      body,
      sprintf("  <note>TRUNCATED at %s bytes (--max-chars).</note>", format(max_len, big.mark = ","))
    )
  }
  body <- c(body, "</repomix_fallback>")
  body
}

    \small\raggedright\color{bodyGrey}

    We observe two independent cross-sectional, non-longitudinal samples of the same subgroup 
    $S$ (e.g., a TIMSS country or a NAEP state): prior scores $X$ at time $t_1$

    \vspace{4pt}
    We map scores to reference-quantiles (pseudo-observations) using fixed reference marginal CDFs:

    \vspace{4pt}
    \hspace{5pt}1.~Prior reference quantiles $U = F_X^{\mathrm{ref}}(x_i)$ and

    \vspace{1pt}
    \hspace{5pt}2.~Current reference quantiles $V = F_Y^{\mathrm{ref}}(y_j)$.

    \vspace{4pt}
    Crucially, there is \emph{no student-level linkage} between these 
    samples---we cannot match any $u_i$ to its corresponding $v_j$.

    \vspace{4pt}
    Panel~A shows the two \emph{univariate} marginals plotted on the same 
    reference-quantile axis (``$u$ or $v$'' in $[0,1]$). This is the 
    information available in TIMSS/NAEP-style designs when cohorts are 
    sampled independently (with survey weights, when applicable).
    
    \vspace{4pt}
    After the reference-quantile transform, $U$ and $V$ summarize the observable evidence.
    All subsequent inference proceeds from these marginals plus an externally supplied
    copula dependence structure.

%%%%
%%%% Panel B1 text: Explanation of regime reverse-engineering
%%%%
\documentclass[10pt]{article}
\usepackage[paperwidth=7.65in,paperheight=11.4in,margin=0in]{geometry}
\usepackage[svgnames]{xcolor}
\usepackage{amsmath}
\usepackage{../../../../../../Papers/Betebenner_Braun/Paper_1/styles/dataimago}

\input{step3_styles}

\pagestyle{empty}
\begin{document}

\noindent
\begin{minipage}[t]{7.65in}
  \vspace{0.05in}
  \hspace{0.15in}%
  \begin{minipage}{7.35in}
    \small\raggedright\color{bodyGrey}

    The mathematical bridge connecting the observed, unlinked marginals (Panel~A) and the recovered latent SGPc regime (Panel~C)
    has two ingredients:
    \begin{enumerate}
      \item A baseline copula $C_0$ providing a dependence template from prior reference-quantiles $U$ to current reference-quantiles $V$.$^\mbox{1}$
      \item A stochastic growth regime $H$ that governs how subgroup $S$ allocates conditional percentiles within that template.$^\mbox{2}$
    \end{enumerate}
    
    \vspace{1pt}
    Together, $C_0$ and $H$ define a \emph{forward map} from a candidate regime to a \emph{predicted} current-grade marginal CDF.
    Panel~B2 visualizes this map via the induced $F_H(v)$, and Panel~B1 \emph{inverts} it by choosing the regime whose $F_H$
    best matches the observed current marginal $F^{\mathrm{obs}}_{V,S}$.

    \vspace{4pt}
    Let $C_0$ be a baseline copula. $C_0$ induces the conditional CDF (transition kernel)
    \[
      \Fzero(v\mid u)\;=\;\Pr(V\le v\mid U=u)\;=\;\frac{\partial}{\partial u}C_0(u,v).
    \]

    \vspace{1pt}
    Its inverse in $v$ (the conditional quantile kernel) is
    \[
      Q_0(p\mid u)=\Fzero^{-1}(p\mid u).
    \]

    \vspace{1pt}
    Intuitively, for each starting quantile $u$, the kernel $\Fzero(\cdot\mid u)$ 
    describes the distribution of possible ending quantiles $V$ under the baseline 
    dependence structure $C_0$.

    \vspace{4pt}
    Let $P\in[0,1]$ be a random variable (a latent SGPc on the $0$--$1$ scale) 
    and let $p$ denote a realization in $[0,1]$. A \emph{growth regime} $H$ is the 
    distribution of $P$, represented by its CDF
    \[
      H(p)\;:=\;\Pr(P\le p),\qquad p\in[0,1].
    \]
    
    \vspace{1pt}
    Given $U=u$ and a draw $P=p$, the model generates an outcome percentile by$^\mbox{3}$
    \[
      V \;=\; Q_0(P\mid U=u).
    \]

    \vspace{1pt}
    The uniform regime $H(p)=p$ (i.e., $P\sim\mathrm{Uniform}(0,1)$) corresponds to occupying the 
    baseline kernel with no tilt. Departures from $H(p)=p$ tilt the growth regime mass toward 
    lower or higher conditional percentiles relative to the baseline regime.

    \vspace{4pt}
    Although we do not observe linked pairs $(u,v)$ in TIMSS- or NAEP-style settings, 
    the model implies a forward map from the observed prior marginal $F_U$ to the 
    predicted current marginal $F_H$. For any fixed $u$,
    \begin{eqnarray*}
      \Pr(V\le v\mid U=u)
      &=& \Pr\bigl(Q_0(P\mid u)\le v\bigr) \\
      &=& \Pr\bigl(P\le \Fzero(v\mid u)\bigr) \\
      &=& H\bigl(\Fzero(v\mid u)\bigr).
    \end{eqnarray*}

    \vspace{4pt}
    Therefore, by the law of total probability, the subgroup's predicted current-grade 
    marginal CDF is
    \begin{eqnarray*}
      \FH(v)
      &=& \Pr(V\le v) \\
      &=& \mathbb{E}_{U}\left[\,H\bigl(\Fzero(v\mid U)\bigr)\right] \\
      &=& \int_0^1 H\bigl(\Fzero(v\mid u)\bigr)\,dF_U(u) \\
      &\approx& \frac{\sum_{i=1}^{n} w_i\,H\bigl(\Fzero(v\mid u_i)\bigr)}{\sum_{i=1}^{n} w_i},
    \end{eqnarray*}

    \vspace{1pt}
    where $\{u_i,w_i\}$ are the observed prior pseudo-observations and 
    survey weights for the subgroup (i.e., a weighted empirical approximation to $F_U$).

    \vspace{4pt}
    We estimate the subgroup's growth regime by searching over an admissible 
    class $\mathcal{H}$ of candidate CDFs on $[0,1]$. Panel~B1 shows the heat 
    map of $\mathcal{H}$ over the \emph{Beta regime family}
    \[
      \mathcal{H}_{\mathrm{Beta}}
      =\left\{\,H_{m,\kappa}(\cdot)\;:\;P\sim\mathrm{Beta}(\kappa m,\kappa(1-m)),\;0<m<1,\;\kappa>0\,\right\},
    \]
    
    \vspace{1pt}
    where $m=\mathbb{E}[P]$ controls the regime center (mean SGPc on the 0--1 scale) and
    $\kappa$ controls concentration (dispersion of latent SGPc).$^\mbox{4}$
    
    \vspace{4pt}
    For each candidate $H\in\mathcal{H}$, Panel~B2 provides the 
    induced \emph{predicted} current-grade marginal
    \[
      F_{H}(v)\;=\;\mathbb{E}_{U}\left[\,H\bigl(\Fzero(v\mid U)\bigr)\right].
    \]

    \vspace{4pt}
    The growth regime estimate for subgroup $S$ is defined by the minimum-distance problem
    \[
      \widehat{H}_S \;=\;
      \argmin_{H\in\mathcal{H}_{\mathrm{Beta}}}\;
      \Wone\bigl(F^{\mathrm{obs}}_{V,S},\,F_{H}\bigr),
    \]

    \vspace{1pt}
    where
    \[
      \Wone(F,G)=\int_0^1 \bigl|F(v)-G(v)\bigr|\,dv
    \]

    \vspace{1pt}
    is the Wasserstein-1 (earth mover's) distance between the observed and predicted current-grade marginal CDFs.
    
    \vspace{4pt}
    The heat map displays $\log_{10}$ Wasserstein--1 distance over $(m,\log_{10}\kappa)$: lighter 
    regions indicate candidate regimes whose induced $F_H$ more closely matches $F^{\mathrm{obs}}_{V,S}$.
    The marked optimum corresponds to $\widehat{H}_S$ (equivalently, $(\hat m,\hat\kappa)$).
    For reference, the uniform regime $H(p)=p$ occurs at $m=0.5$ and $\kappa=2$ (i.e., $\mathrm{Beta}(1,1)$),
    indicated by the $U(0,1)$ marker.

  \end{minipage}
  \vspace{0.1in}
\end{minipage}

  \vspace{0.05in}
  \hspace{0.15in}%
  \begin{minipage}{3.45in}
    \small\raggedright\color{bodyGrey}

    The output of Panels~B1--B2 is a subgroup-specific \emph{estimated growth regime}
    $\widehat{H}_S$, where $\widehat{H}_S$ is a cumulative distribution function (CDF) on $[0,1]$
    for a latent conditional-percentile random variable $P_S$ (SGPc on the $0$--$1$ scale):
    \[
      \widehat{H}_S(p)\;=\;\Pr(P_S \le p),\qquad 0\le p\le 1.
    \]
    
    \vspace{1pt}
    In words, $\widehat{H}_S$ describes how subgroup $S$ allocates conditional ranks
    \emph{within} the baseline dependence template $F_0(\cdot\mid u)$.
    
    \vspace{4pt}
    Panel~C displays the \emph{distribution of} $P_S$ (typically via its density
    $f_{\widehat{H}_S}(p)=\widehat{H}_S'(p)$ when $\widehat{H}_S$ is smooth), not the CDF itself.
    Thus the ``Best-fit'' curve is the density corresponding to the fitted CDF
    (i.e., $P_S \sim \widehat{H}_S$). The dashed grey ``Uniform'' reference corresponds to the
    uniform regime $H(p)=p$ (equivalently $P\sim\mathrm{Unif}(0,1)$), which places no tilt on
    conditional percentiles relative to the baseline kernel.
    
    \vspace{4pt}
    Because we restrict the candidate regime class $\mathcal{H}$ to the Beta family in Panel~B1,
    the fitted regime implies
    $P_S\sim\mathrm{Beta}(\kappa m,\kappa(1-m))$:
    the mean $m=\mathbb{E}[P_S]$ sets the regime center (reported as mean SGPc $=100m$),
    and $\kappa$ controls concentration (dispersion of latent SGPc).
    
    \vspace{4pt}
    The vertical reference lines mark mean SGPc under the uniform regime (50),
    the generating ``True'' regime ($\trueRegimeMean$), and the recovered best-fit regime
    ($\inferredRegimeMean$). In applications, the primary outputs are $\widehat{H}_S$
    (with uncertainty bands) and summary functionals such as mean/median SGPc and
    tail/bucket probabilities.
