# STEP 3 Analytic Explanation Figure

This folder contains a synthetic, horizontal multi-panel infographic that explains how STEP 3
infers a latent growth regime `H_S` (SGPcFlow) from unlinked cross-sectional pseudo-observations.

Canonical figure theme/title: **Longitudinal Inference Without Longitudinal Data**

The figure is the primary methodological exhibit for Chapter 4 of the paper, illustrating the
four-step LIwLD workflow:

```
A  →  B1  →  B2  →  C
observe marginals  →  invert (m,κ)  →  forward CDF check  →  infer regime
```

The default layout is intentionally wide (16 × 7 inches), left-to-right causal story.

---

## What the Figure Shows

- **Panel A:** Independent U (prior) and V (current) marginal densities — no student-level
  pairs. Illustrates the cross-sectional input structure.
- **Panel B1:** Reverse-engineering of regime parameters (mean m, concentration κ) via
  minimum-distance search over the canonical Beta family:
  `H_hat_S = argmin_{H ∈ H_Beta} W_1(F_obs_V, F_H)`
- **Panel B2:** Forward CDF check — observed `F_obs(v)` vs predictions under uniform, inferred,
  and TAMP (comonotonic) references, using the analytic identity:
  `F_H(v) = E_U[ H( F_0(v|U) ) ]`
- **Panel C:** Inferred growth regime density `f_S(p) = H_S'(p)` vs uniform baseline and true
  synthetic regime.

The identifying assumption illustrated throughout: **P ⊥ U** within subgroup.

## Data Source Modes

The figure can be rendered using either synthetic data or real Phase A results:

**Mode 1 — Synthetic (default):**
Uses the analytic RDS generated by `step3_analytic_explanation.R`. The default scenario
illustrates a low-growth subgroup (true mean SGPc ≈ 39, n = 3,500, t-copula ρ = 0.72, df = 8).

**Mode 2 — Real Phase A data:**
Uses `../../../results/phase_a_analytic_payload.rds` (the actual Phase A condition run).
Activate with the `STEP3_EXPORT_MODE` environment variable before calling `step3_export_data.R`:
```bash
STEP3_EXPORT_MODE=PHASE_A_REAL_DATA Rscript PSTricks/step3_export_data.R
```
This substitutes the synthetic scenario with the actual district-level validation data, making
the infographic directly relevant to the paper's empirical results.

## Build

From project root:

```r
source("STEP_3_LIwLD/Figures/Analytic_Explanation/step3_analytic_explanation.R")
```

Writes outputs to `STEP_3_LIwLD/Figures/Analytic_Explanation/outputs/`.

For the publication-grade PSTricks/LaTeX version:

```bash
cd STEP_3_LIwLD/Figures/Analytic_Explanation/PSTricks/
Rscript step3_build_pstricks.R
```

See `PSTricks/README.md` for the full build pipeline and prerequisites.

## Main Tuning Knobs (Synthetic Mode)

Edit `STEP3_ANALYTIC_EXPLANATION_CONFIG` in `step3_analytic_explanation.R`:

| Parameter | Default | Effect |
|-----------|---------|--------|
| `true_regime_mean` | ~0.39 | True mean SGPc for synthetic subgroup |
| `n_students` | 3500 | Sample size |
| `copula_rho` | 0.72 | Baseline t-copula correlation |
| `copula_df` | 8 | Baseline t-copula degrees of freedom |
| `figure_width` | 16 | Layout width in inches |
| `figure_height` | 7 | Layout height in inches |

## PSTricks Publication Version

A publication-grade PSTricks/LaTeX version is in the `PSTricks/` subfolder. It renders the
same 4-column story as a 2×4 layout (top row: graphic panels A/B1/B2/C; bottom row: typeset
mathematical text). Build with:

```bash
cd PSTricks/
Rscript step3_build_pstricks.R
```

The current active version is **V2** (layout: A → B1 → B2 → C with shared B1/B2 text panel).
An archived V0 snapshot with a different panel ordering is preserved in `PSTricks/V0_030126/`
for historical comparison.

See `PSTricks/README.md` for full details on the build pipeline, notation macros, and
AI context artifact generation.
